## 面板服还是 VPS 游戏云：先看你要不要 root

面板服给的是 50Mbps 固定上行，VPS 给的是 10–15M 按配置走的带宽。这个差别反直觉，但确实是资料里明确写着的：面板服带宽更宽，代价是没有系统级登录权限。

面板游戏云基于雨云自研面板，内置 MCSManager，传服务端、切版本、装插件都在网页上完成，有备份、MySQL、文件管理，开机即用。它跑在 NAT 上，没有独立 IP，靠端口映射对外提供服务，对泰拉瑞亚这种只需要一个游戏端口的服务完全够。

VPS 游戏云给完整系统权限，Windows 和 Linux 都行，可以 SSH 或远程桌面进去自己搭环境，可选独立 IP。适合要同时跑网站、语音服、MCSM 加 Nginx 反代这类多服务的场景。

判断规则很简单：只跑一个泰拉瑞亚服、不想碰命令行，选面板服；需要独立 IP、要自己控制运行环境、或者一台机器上还要跑别的东西，选 VPS。新手买 VPS 最常见的结果是花更多钱，然后卡在装 .NET 和配防火墙那一步。

## 按人数和 MOD 选配置：16 人是个硬上限

泰拉瑞亚官方说明，服务端默认支持最大 16 名玩家同时在线（1.4.0.1 版本之后）。这意味着买"20 人档""50 人档"的配置没有实际意义，除非你打算同时开多个世界或多个服。

配置分三档：

- **2–4 人，原版或少量 MOD**：1 核 2G 够用，流畅跑原版没问题。
- **4–8 人，原版或中等 MOD**：2 核 4G，这是多数小圈子的稳妥选择。
- **8 人以上，或 tModLoader 大型整合包**：4 核 8G 起，模组加载和世界生成才不会卡。

选型上有一条比核心数更重要的原则：泰拉瑞亚服务端吃单核主频。tModLoader 尤其明显，模组越多，单核性能的影响越大。这也是雨云把 Ryzen 9 5900X（4.8GHz）、Ryzen 9 7950X（5.7GHz）、i9-14900K（单核最高 6.3GHz）这类高主频 U 放在游戏云产品线上的原因。同样 4G 内存，高主频机型跑 tModLoader 的体感差别比多加两个核更直接。

tModLoader 还有个内存门槛：2G 能起，但装灾厄这类大模组，4G 更稳。买 2G 档跑大型整合包，大概率会在加载阶段就失败。

## 开服实操：五步和一个容易写错的参数

面板服开服不需要技术背景，新手照着走大概 10 到 15 分钟。

1. 注册账号并绑定微信，领首月 5 折券。
2. 购买游戏云，配置页选 **Terraria + tShock**（或原版服务端），选机房。大陆玩家就近选，跨境走香港 BGP 优化线路。
3. 进控制台，下拉到 MCSManager 面板，按提示启动。
4. 按需要在启动脚本末尾加参数。
5. 看到 `Server started`，把 IP 和端口发给朋友。

启动参数里最容易出错的是难度编号：

- `-maxplayers 8` 设置最大玩家数
- `-password 你的密码` 给服务器加密码
- `-difficulty 1` 设置难度，**0 是经典、1 是专家、2 是大师、3 是旅程**
- `-language zh-Hans` 让服务端输出中文

难度编号写错不会报错，只是世界按你没预期的模式生成，玩到一半才发现就得重开。另外两个常见坑：云厂商安全组没放行游戏端口，朋友连不进来；tModLoader 本体更新后客户端版本对不上，进服直接断连。

## 进阶：tModLoader 的两条路

跑模组有两条路，成本差得不少。

**路线一，用雨云面板服。** 已有 tModLoader 搭建教程，更新服务端文件后改一下启动脚本就行，全程面板操作，不需要 Linux 知识。省心，但要付套餐费。

**路线二，自己有 Linux VPS 的话，用开源面板自建。** 项目叫 `tml-panel`（MIT 协议），定位是单实例的 tModLoader 专用服，裸机加 systemd，不依赖 Docker。内存 2G 起，装灾厄这类大模组建议 4G。部署两条命令：


git clone https://github.com/KoishiVI2035/tml-panel.git
cd tml-panel && sudo bash deploy/install.sh --cn


国内机器直连 GitHub 下 tModLoader 很慢，`--cn` 会让 Node、npm 和本体下载都走国内镜像。跑完输出访问地址和一次性 setup token，首次设管理员密码要用。

它的默认安全设计值得说清楚：面板只监听 `127.0.0.1`，要从本地访问得先做 SSH 端口转发 `ssh -L 8765:127.0.0.1:8765 root@IP`。面板以 root 身份运行，**面板密码等同于 root 密码**，别设弱口令。游戏端口默认 7777/TCP，同样要在云厂商安全组放行。

日常功能覆盖得比较全：网页里发 `save`、`say`、`playing`、`kick`，本体一键升级带失败自动回滚，可视化改 `serverconfig.txt`，工坊模组自动递归补前置依赖。首启要下 .NET 并生成世界，弱网下超过 10 分钟属于正常。当前边界是单实例、x86_64，Docker 和多实例还在 roadmap 上。

这条路的实际成本就是一台 VPS 的钱，适合本来就有机器、又想完全掌控的人。不愿意折腾运维，路线一更省时间。

## 谁不适合买

中小厂商在极端峰值时段的稳定性相比阿里腾讯这类大厂有差距。开几十上百人同时在线的公益服、对 SLA 有硬性要求的，需要另外评估。这是论坛和测评里被提到较多的一点，不是个别现象。

需要独立 IP 跑特殊端口服务的，NAT 机型不适用，得选 VPS 并加购独立 IP。只玩一两次的，先花 1 元试用 24 小时，或者选动态计费按日结算，比包月划算。
